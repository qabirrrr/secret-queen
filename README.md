# Secret Queen

A chess variant where each side selects a pawn to secretly behave like a queen

## How To Play
It's just like regular chess

But instead of checkmating, you capture the king to win

There are no illegal moves, since that would reveal the secret queen

You can also en passant a queen, which is my favourite part about this

## How To Host
This game is self hosting

You can host the server yourself and play with your friends

To just play locally, enter "localhost" when prompted for the host
